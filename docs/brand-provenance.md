# shuvshow brand provenance

The shuvshow devil stage mark was created for this fork on August 13, 2026. Its horn-and-tail geometry
belongs to the same operator-owned visual family as shuv2code and SHark; the interior stage/window and
stacked surfaces are original to shuvshow.

Canonical sources:

- `assets/brand/shuvshow-mark.svg`: fixed-color master.
- `assets/brand/shuvshow-mark-mono.svg`: theme-aware `currentColor` master.

Canonical colors:

- Midnight Brick: `#D35C46`.
- Night Ink: `#0C1119`.
- Signal Light: `#E7ECF3`.

The SVG masters are hand-authored source assets. Browser and social derivatives should be generated
from these files rather than redrawn. If deterministic raster derivatives are introduced, record their
renderer version and hashes here.
